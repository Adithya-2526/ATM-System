# ATM-System
The ATM System is a software project that simulates banking operations through an ATM. It allows users to securely log in using their card and PIN, check balance, withdraw or deposit cash, transfer funds, change PIN, and view transaction history. The system focuses on security, accuracy, database management, and user-friendly transactions.
This project is created for academic demonstration purpose only
